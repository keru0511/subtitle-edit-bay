# 初回文字起こしの実音声CI素材

Kokoro Speech Dataset v1.3の公開サンプルから4録音を選び、原データのまま保存しています。合計約17秒、約310KBです。合成音声ではありません。

- 配布元: https://github.com/kaiidams/Kokoro-Speech-Dataset
- 固定リリース: https://github.com/kaiidams/Kokoro-Speech-Dataset/releases/tag/1.3
- 配布アーカイブ: `kokoro-speech-v1_3-sample-flac.zip`
- 録音: LibriVoxのekzemplaro
- 文章: 青空文庫の田山花袋『田舎教師』、夏目漱石『こころ』
- 分割・注釈: Katsuya Iida
- 配布元のライセンス表記: パブリックドメイン（READMEのLicense節を参照）

`manifest.json` に原ファイル名、SHA-256、元メタデータから空白だけを除いた正解文、音声長を記録しています。配布元の注釈は自動アラインメントによるもので、人手で作成した単語時刻ラベルではありません。

CIではFFmpegで16kHzモノラルPCMへ変換し、70秒の音声の2・14・32・46秒の位置に配置します。その他は無音で、23〜28秒と58〜63秒だけ固定seedの低振幅雑音を加えます。自然な「うんうん」の反復も含みます。元音声にない言葉を正解文へ追加したり、認識結果に合わせて正解文を書き換えたりしません。

評価しきい値は、文字誤り率25%以下、比較対象からの文字誤り率・挿入・脱落の悪化なし、発話区間外の文字と時刻欠損なしです。時刻の許容幅は区間端から0.4秒です。これは粗い回帰検査の基準であり、精度改善を示す実測値から決めたものではありません。実行結果に合わせて自動で緩めません。

この小さな朗読素材だけでは、ゲーム音、複数人の重なり、叫び声、小声、数十分の録音のずれは評価できません。実際の問題録音は別途追加が必要です。
