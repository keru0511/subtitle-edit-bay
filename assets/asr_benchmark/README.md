# 初回文字起こしの実音声CI素材

Kokoro Speech Dataset v1.3の公開サンプルから4録音を選び、原データのまま保存しています。合計約17秒、約310KBです。合成音声ではありません。

- 配布元: https://github.com/kaiidams/Kokoro-Speech-Dataset
- 固定リリース: https://github.com/kaiidams/Kokoro-Speech-Dataset/releases/tag/1.3
- 配布アーカイブ: `kokoro-speech-v1_3-sample-flac.zip`
- 録音: LibriVoxのekzemplaro
- 文章: 青空文庫の田山花袋『田舎教師』、夏目漱石『こころ』
- 分割・注釈: Katsuya Iida
- 配布元のライセンス表記: パブリックドメイン（READMEのLicense節を参照）

`manifest.json` に原ファイル名、SHA-256、元メタデータから空白だけを除いた正解文、音声長を記録しています。配布元の注釈は自動アラインメントによるもので、人手で作成した単語時刻ラベルではありません。

CIではFFmpegで16kHzモノラルPCMへ変換し、120秒の音声の2・14・32・46秒の位置に元録音を配置します。その他は無音で、23〜28秒と58〜63秒だけ固定seedの低振幅雑音を加えます。自然な「うんうん」の反復も含みます。元音声にない言葉を正解文へ追加したり、認識結果に合わせて正解文を書き換えたりしません。

評価しきい値は、文字誤り率25%以下、比較対象からの文字誤り率・挿入・脱落の悪化なし、発話区間外の文字と時刻欠損なしです。時刻の許容幅は区間端から0.4秒です。これは粗い回帰検査の基準であり、精度改善を示す実測値から決めたものではありません。実行結果に合わせて自動で緩めません。

この小さな朗読素材だけでは、ゲーム音、複数人の重なり、叫び声、小声、数十分の録音のずれは評価できません。実際の問題録音は別途追加が必要です。

## 表記差の扱い

初回の実認識で「あとから→後から」などを発言の脱落として数える問題が分かったため、`equivalent_spellings` にこの素材で同じ発言を表せる表記を明示しています。「耳に入る／耳にはいる」「家だから／うちだから」「と言って／といって」「後から／あとから」「おじは／叔父は」の5組です。認識結果から自動生成する辞書ではなく、評価素材の注釈です。

元の正解文、認識JSON、表記差を含む `raw_cer` は保持します。合否に使う `cer` と編集操作数はこの5組を揃えた値です。反復や言葉の欠落を除去する正規化はせず、数値のしきい値も変更していません。この区別によって表記改善と発言の誤認識を混同しないようにします。

## 聞き取り条件の追加

原録音4件を再利用し、次の加工済み発話を追加します。原ファイル、正解文、発話長は変更せず、加工パラメータと配置をmanifestに固定します。追加の音声バイナリや外部ダウンロードは不要です。

| 条件 | 配置 | 加工 |
| --- | --- | --- |
| low_volume | 74秒 | 1件目を−18dBへ減衰 |
| speech_noise | 84秒 | 2件目に固定seedの白色雑音をSNR 15dBで重畳 |
| tonal_background | 94秒 | 3件目に220/330/440Hzの合成和音をSNR 15dBで重畳 |
| band_limited | 104秒 | 4件目をFFmpegの300Hzハイパス・3000Hzローパスで帯域制限 |

さらに114〜118秒には声のない330Hzの合成音を配置します。従来の無音・雑音の負例も残します。合成和音は実際のBGM・ゲーム効果音ではなく、音量低下は自然な小声・ささやき声ではありません。話者、文章、録音環境の多様性は増えていません。叫び声、笑い声、複数人の同時発話、長時間音声は引き続き未検証です。

全体の判定に加え、cleanを含む5条件でも同じ上限・回帰基準を適用します。条件別の認識文は各文字の時刻の中点が配置区間（許容幅を含む）に入るかで割り当てます。条件外の誤生成や時刻欠損は全体の判定に残すため、分類できない文字が評価から消えることはありません。条件別CERと全文・生のCERをレポートに保存します。
