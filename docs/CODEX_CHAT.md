# Codexチャット

## セットアップ

Codexチャットは、ローカルに導入済みのCodex CLIが提供するApp Serverを再利用します。対応するCodex CLIを導入し、`codex --version` を実行できる状態でアプリを起動してください。複数の実行ファイルがある場合は、`CODEX_EXECUTABLE` で使用するファイルを指定できます。

アプリは `codex app-server --listen stdio://` を子プロセスとして起動します。待受ポートや外部WebSocketは開きません。通信仕様は[OpenAIのCodex App Serverドキュメント](https://developers.openai.com/codex/app-server)に従います。

## ログインとログアウト

1. 画面右上の `Codexチャット` で `ログイン` を押す
2. 開いたブラウザでChatGPTの認証を完了する
3. 表示が `ログイン済み` に変わったら `開く` を押す

ブラウザが自動で開かない場合は、認証待ちの間に表示される `ブラウザを開く` を押してください。アカウントを切り替える場合はパネル内の `再ログイン`、利用を終了する場合は `ログアウト` を使用します。

表示する状態は、接続中、未ログイン、ログイン待ち、ログイン済み、認証エラー、切断です。切断した場合は `再接続` を押し、必要に応じて再ログインしてください。Codexへ接続できない場合も、通常の文字起こし、字幕編集、音量調整、書き出しは引き続き利用できます。

## チャットとモデル

ログイン後にパネルを開き、App Serverから取得した利用可能モデルを選択してメッセージを送信します。応答は受信した部分から順に表示されます。送信中、応答受信中、停止中、送信失敗はパネル上部に表示され、処理中は `停止` を使用できます。

モデルは固定リストではなく `model/list` の結果から表示します。選択したモデルはローカルの `.gui/runtime_config.json` に `shared.codex_model` として保存され、アプリ再起動後も使用されます。各送信の `turn/start` に選択モデルを指定するため、変更は次のメッセージから反映されます。保存済みモデルが利用できなくなった場合はエラーを表示し、App Serverが示す既定モデルへ切り替えます。

`新規` は画面内の会話を消去し、新しいCodex threadを次の送信時に開始します。会話本文はGUI設定へ保存しません。

## セキュリティと機能境界

- ChatGPTのtokenやAPIキーはアプリで受け取らず、Codex CLIの管理する認証フローを使用する
- 認証URL、token、会話本文を `.gui/runtime_config.json` や通常ログへ書き込まない
- App Serverとはstdioで接続し、チャットthreadは `approvalPolicy=never`、`sandbox=readOnly` で開始する
- 各turnの読み取り範囲はアプリのworkspaceルート配下とOSの最小限のplatform defaultに制限し、ユーザーディレクトリ全体を読み取れる状態にしない
- コマンド実行やファイル変更のapproval要求を自動承認しない
- 入力要求、MCP elicitationなど未対応のserver requestは明示的に拒否し、応答待ちで停止させない

このパネルはログイン、通常チャット、モデル選択だけを担当します。現在の字幕や再生位置をチャットへ自動添付する操作バーは #239、文字起こしを前提としない機能別ワークフローは #241 の範囲です。字幕への編集提案、差分確認、明示適用は既存の `Codexで編集` パネルが別の責務として扱います。
