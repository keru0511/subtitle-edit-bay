# Codex字幕編集

## 対応範囲

Codex編集は、字幕本文・時刻・話者・フォントなどの編集案を生成し、利用者が差分を確認してから適用する機能です。動画・音声ファイルそのものは送信せず、選択した字幕のID、時刻、本文、話者、字幕設定だけをcontextとして渡します。

編集案はプロジェクトへ直接書き込まれません。`送信`、差分確認、`適用` の順で操作し、適用前は元プロジェクトとファイルを変更しません。適用後も既存の保存、Undo/Redo、ASS更新、動画書き出しを明示的に操作してください。

## 導入と検出

Codex CLIを導入した環境では、アプリ起動後に次の優先順位で検出します。

1. `CODEX_EXECUTABLE` で指定した実行ファイル
2. プロジェクトの `.venv` 配下
3. `codex` がPATHに存在する場所

検出後は `codex app-server --listen stdio://` をローカル子processとして起動します。MVPはstdioだけを使用し、待受ポートやWebSocket接続を開きません。対応バージョン、未導入、未認証、接続失敗はGUIで区別して表示します。

対応バージョンは `0.1.0 <= version < 1.0.0` です。`--version` が成功しても、出力にCodexの識別子がなく、semverを解析できず、またはこの範囲外の場合は採用しません。

Installer版、ZIP版、Git checkout版は診断情報で区別されます。Codexが未導入でも通常の手動字幕編集は利用できます。

## 使い方

1. 字幕編集画面を開き、`Codexで編集` パネルを展開する
2. `selected`、`current`、`time_range`、`all` から対象範囲を選ぶ
3. 依頼文を入力して`送信`する
4. 返された字幕ごとの差分、警告、対象件数を確認する
5. 変更を選択して`適用`、または`破棄`する
6. 適用後に字幕一覧、プレビュー、タイムラインを確認して保存する

Codexが処理中に手動編集を行った場合はrevision競合として提案を適用しません。現在の状態を確認してから再送信してください。

## データと認証の注意

- APIキー、Bearer token、authorization headerはプロジェクト、通常ログ、診断コピーへ保存しない
- 動画、音声、プロジェクトの絶対パスはCodex contextへ含めない
- Codexの入力文と対象字幕が外部サービスへ送信されることを初回利用時に確認する
- command approvalやfile change approvalはMVPで自動承認しない
- 実アカウントを使う統合テストは通常CIから分離する

## テストと診断

通常のテストはfake app-serverを使用し、認証情報を要求しません。実接続を確認する場合だけ、環境変数で明示的にopt-inします。

~~~powershell
$env:RUN_CODEX_INTEGRATION = "1"
~~~

失敗時はGUIの処理ログから、Codexの検出結果、接続状態、Turn状態、エラーをコピーできます。診断情報にはredaction後の値だけを含め、字幕本文と認証情報を通常のコピー内容へ含めません。

## 制約

- CodexによるプロジェクトJSONの直接編集は行わない
- 確認なしの自動適用、自動レンダリング、音量・ショート動画編集は対象外
- リモートWebSocket接続とCodexアカウント・APIキーの独自管理は対象外
