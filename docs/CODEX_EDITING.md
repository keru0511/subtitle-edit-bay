# Codex字幕編集

## 対応範囲

Codex編集は、字幕本文・時刻・話者・フォントなどの編集案を生成し、利用者が差分を確認してから適用する機能です。動画・音声ファイルそのものは送信せず、選択した字幕のID、時刻、本文、話者、字幕設定だけをcontextとして渡します。

編集案はプロジェクトへ直接書き込まれません。`送信`、差分確認、`適用` の順で操作し、適用前は元プロジェクトとファイルを変更しません。適用後も既存の保存、Undo/Redo、ASS更新、動画書き出しを明示的に操作してください。

## 導入

公式Python SDK `openai-codex==0.163.0` と、そのSDKに対応する固定版Codex本体をアプリのセットアップで導入します。手動で導入したCLIの探索、独自のバージョン判定、`CODEX_EXECUTABLE` の指定は行いません。

SDKの標準機能でApp Serverへstdio接続し、認証・通知・構造化出力を利用します。既存のCodex認証を再利用でき、未認証なら共通チャットのログイン操作から認証します。WindowsでもSDK標準の起動方式を使用します。

Installer版、ZIP版、Git checkout版は引き続き診断情報で区別されます。SDKやApp Serverの起動に失敗しても通常の手動字幕編集は利用できます。

## 使い方

1. 編集プロジェクトを開き、共通サイドバーの `Codexチャット` を開く
2. `自動`、`選択字幕`、`再生位置`、`時間範囲`、`全字幕` から対象範囲を選ぶ
3. 依頼文を入力して `送信` する
4. チャット内に表示された字幕ごとの差分、警告、対象件数を確認する
5. 変更を選択して `選択した変更を適用`、または `破棄` する
6. 適用後に字幕一覧、プレビュー、タイムラインを確認して保存する

Codexが処理中に手動編集を行った場合はrevision競合として提案を適用しません。現在の状態を確認してから再送信してください。

## データと認証の注意

- APIキー、Bearer token、authorization headerはプロジェクト、通常ログ、診断コピーへ保存しない
- 動画、音声、プロジェクトの絶対パスはCodex contextへ含めない
- Codexの入力文と対象字幕が外部サービスへ送信されることを初回利用時に確認する
- command approvalやfile change approvalはMVPで自動承認しない
- 実アカウントを使う統合テストは通常CIから分離する

## テストと診断

通常CIは公式SDKと模擬App Serverを接続し、認証情報を使わずに検証します。SDK同梱の実ランタイムも、一時領域を保存先にして起動・初期化を確認します。実アカウントへのログインやモデル推論は手動確認として分離します。

失敗時はGUIの処理ログから、SDKのバージョン、接続状態、Turn状態、エラーをコピーできます。診断情報にはredaction後の値だけを含め、字幕本文と認証情報を通常のコピー内容へ含めません。

## 制約

- CodexによるプロジェクトJSONの直接編集は行わない
- 確認なしの自動適用、自動レンダリング、音量・ショート動画編集は対象外
- リモートWebSocket接続とCodexアカウント・APIキーの独自管理は対象外
