# コンテキスト操作バーとCodexサイドバー

Issue #239 では、メイン画面の工程操作をワークフローステッパー直下のコンテキスト操作バーへ集約する。

## 操作の責務

- 主操作は素材準備前の文字起こし、またはプロジェクト作成後の字幕編集を表示する
- 副操作として辞書設定、音量調整、ショート動画作成を状態に応じて表示する
- 書き出し、設定保存、出力先を開く、処理停止は同じ操作バーから継続して利用できる
- 実行条件を満たさない場合は主操作の近くに理由を表示する
- 詳細設定は操作バーのボタンからポップアップで編集し、既存の設定保存処理を利用する

## Codex領域

右サイドバーは `CodexSidebarContainer` として確保する。`codexChatPanel` が #238 のチャット本体を配置するスロットであり、このIssueでは認証、送受信、モデル変更を実装しない。

## レイアウト保証

メイン画面は標準サイズ `1520x940`、最小サイズ `1220x760` を維持する。操作バーは中央の動画領域の直前に配置し、右サイドバーの固定幅と合わせても主要操作が欠けたり重なったりしないようにする。

既存のGUI回帰テストが使用する `objectName` は `ContextActionBar` 内でも維持するため、操作の検索とバックエンドAPIの呼び出し契約を変更しない。
