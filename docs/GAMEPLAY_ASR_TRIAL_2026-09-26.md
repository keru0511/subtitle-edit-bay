# 社畜部の実況音声による初回認識の試行（2026-09-26）

ユーザーが自身のチャンネルの利用を許可した [実況動画](https://www.youtube.com/watch?v=vs833guKQA8) から、ゲーム音と会話を含む区間を一時取得し、製品の `src.whisperx_runner` で初回認識しました。動画や音声、認識JSONはリポジトリに収録していません。

この試行では、ユーザーが手入力した「一周すると言われとるやん」「そうそう」「腰パンとか時代のものが」「うぉぉぉ」「ひぃぃぃ」などの発言を、問題の区間についての確認済みテキストとして使いました。作業環境から音声を聴覚確認することはできず、区間全体の逐語正解と語ごとの正解時刻は確定していません。YouTubeの自動字幕は場所の探索だけに使い、正解文にはしていません。そのためCERなどの精度値や「発言していない」との断定は出しません。

## 入力と実行条件

| 区間 | 元動画時刻 | 用途 |
| --- | --- | --- |
| 会話の前後 | 1:33:10〜1:34:10（60秒） | 問題の反復・叫びを前後の文脈込みで比較 |
| 該当会話 | 1:33:35〜1:34:00（25秒） | 切り出し長による変化を確認 |
| 自然な反復 | 1:10:05〜1:10:30（25秒） | 「やばい」の反復を含む対照区間 |
| ゲーム音と会話 | 0:29:55〜0:30:35（40秒） | 発話間の空白がある対照区間 |

元音声はYouTubeの形式251（Opus）で取得し、FFmpegでモノラル16 kHz PCMへ変換しました。取得した元音声のSHA-256は `b6b0d183a1ae6269f97cab6a547cdd233c95280e8c8dbc67dd280517fedbf9f0`、60秒区間のWAVは `393be4d0b76298bbb97060c4587eadd514c7e00696a9d6f6daab6e60503d5a2c` です。WhisperX 3.8.6、faster-whisper 1.2.1、CTranslate2 4.8.2、PyTorch 2.8.0、`large-v3 / CPU int8 / 日本語` で実行しました。製品のCUDA float16環境での結果ではありません。

再現時は、権利者の許可を得て元音声をGit管理外の `out/` に置き、次のように同じ区間を切り出します。

```sh
ffmpeg -ss 5590 -t 60 -i out/gameplay/original.webm -ac 1 -ar 16000 -c:a pcm_s16le out/gameplay/context.wav
python -m src.whisperx_runner out/gameplay/context.wav --model large-v3 --device cpu --compute_type int8 --language ja --output_dir out/gameplay/baseline
python -m src.whisperx_runner out/gameplay/context.wav --model large-v3 --device cpu --compute_type int8 --language ja --chunk_size 30 --output_dir out/gameplay/chunk30
```

## 観察結果

同じ60秒に対して一種類の設定だけを変更しました。以下は比較に関係する出力の抜粋です。

| 設定 | 問題区間の出力と影響 |
| --- | --- |
| 現行（反復ペナルティ1.1、区切り15秒） | 「一周すると言われてるやん」「イリシャするらしくて」「こしぱんとかの時代のものがいいいいいい」 |
| 反復ペナルティ1.0 | 「一周するって言われとるやん」はユーザーの表記に近づいたが、「いいいいいい」は残った |
| 区切り30秒 | 「一周すると言われとるやん」は近づき、「いいいいいい」は「うぇーいうぇーい」に変わった。ただし叫び声の正確な表記かどうかは未確認 |
| 確認済み語のヒント「一周、腰パン」 | 「腰パン」は増えた一方、「いいいいいい」の箇所は出力されなかった。ユーザーが示した叫び声を落とした可能性があり、単純な改善とは扱えない |

25秒だけに切ると結果がさらに変わりました。反復ペナルティ1.0では「うぇーいうぇーい」と重複し、区切り30秒では「ジャンプ」「ういいい」などユーザーの提示文にない語が現れました。語ヒントでは「一周するらしくて」「腰パン」が出ましたが、60秒で同じ改善は再現しませんでした。VAD開始閾値だけを0.5から0.4へ下げた25秒の結果は、本文がほぼ同じでした。

二つの対照区間では、語ヒント「一周、腰パン」を渡しても、その語の新たな挿入は認められませんでした。「やばい」の連続も両設定で残りました。ただし対照区間の全文は人手で検証していないため、他の誤りがないことまでは示しません。

今回の結果だけでは、既定の反復ペナルティ、区切り長、VAD値、語ヒントを変更しません。特に「いいいいいい」を消した候補は、実際の叫び声まで削った可能性があります。まず異なるゲーム・音量・BGM・重なり・無音を含む数分以上の素材を聴覚確認し、発話と負例の時刻を確定します。その後に [実況音声の評価手順](GAMEPLAY_ASR_EVALUATION.md) で挿入・脱落・時刻を比較し、採用候補を製品のCUDA float16環境でも確認します。
