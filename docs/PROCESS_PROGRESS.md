# 処理進捗の見方

文字起こし、通常動画の書き出し、ショート動画の書き出しを開始すると、画面下部に共通の処理進捗パネルが表示されます。

- 工程名の `○` は未実行、`●` は実行中、`✓` は完了を示します
- バーと整数の百分率は処理全体の進捗です。同じ処理中に後退しません
- `停止` を押せる処理では、現在の工程をキャンセルできます
- 正常完了時は `100%`、キャンセル時は `Ⅱ`、エラー時は `!` と最後の進捗値を表示します

工程は処理ごとに異なります。不要な工程は表示されず、字幕なしの処理でも現在工程と全体進捗を確認できます。詳細なログや診断情報は画面下部の「システムログ」から確認できます。

システムログには、アプリのバージョンと配布形態、Python・FFmpeg・PyTorch・CUDA、依存関係、読み込んだ設定種別、GUI状態遷移、Codex App Server、QML読込、処理コマンドと処理出力を起動時から時系列で記録します。処理を開始しても起動ログは消去されません。大量の処理出力で表示上限へ達した場合もシステム・警告・エラーは優先して保持され、完全な構造化ログは「ログフォルダを開く」からセッション単位のJSONLとして確認できます。

バックエンドとワーカーの境界では、表示文言とは分離した `PROGRESS_EVENT` 行を使用します。この行には工程IDと進捗だけを含め、ファイルパスや認証情報は含めません。
