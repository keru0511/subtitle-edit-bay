# 字幕ごとの表示行数

この機能は、既存の自動改行ルールを残したまま、字幕編集画面でセリフごとに表示行数を指定するためのものです。

## 基本方針

既定値は `自動` です。`自動` の場合は、従来どおり日本語向けの改行、2行分割、読みやすさ、表示幅、表示時間を考慮した既存ルールで字幕を整形します。

必要な字幕だけ `1行` または `2行` に変更できます。変更した値は `.subtitle-project.json` の各segmentに `subtitle_line_count` として保存され、ASS更新と動画書き出しに反映されます。

## 選択肢

| 表示 | 保存値 | 挙動 |
|---|---|---|
| 自動 | `auto` | 既存の自動改行ルールを使います。既存projectや未指定segmentはこの扱いです。 |
| 1行 | `1` | 可能な限り1行で表示します。長すぎる場合は1行に収まる範囲を優先します。 |
| 2行 | `2` | 既存の2行分割ルールを使い、2行以内に整形します。 |

## GUIでの使い方

1. 文字起こし後、`字幕を編集する` を開きます。
2. タイムラインまたは字幕一覧で対象の字幕を選択します。
3. 画面右下の `表示行数` で `自動` / `1行` / `2行` を選びます。
4. `ASSを更新` でプレビュー用ASSを再生成します。
5. 問題なければ `字幕を焼き付ける` で完成動画を書き出します。

変更は他の字幕編集と同じように履歴、dirty state、自動保存の対象です。`Ctrl+Z` / `Ctrl+Y` で戻す、やり直すこともできます。

## CLI / project JSON

project JSONでは各segmentに次のように保存されます。

```json
{
  "segments": [
    {
      "text": "この字幕だけ1行にしたい",
      "subtitle_line_count": "1"
    }
  ]
}
```

`subtitle_line_count` がない既存projectは `auto` として読み込まれます。不正な値はproject読み込み・保存時にエラーになります。

## 注意点

- この機能は既存の改行スコアリング自体を変更しません。
- `自動` の出力は従来の自動改行ルールを維持します。
- 3行以上の本格対応はこの機能の対象外です。
- 字幕本文に手動で改行を入れる機能ではありません。行数指定に応じて生成時の整形を制御します。
