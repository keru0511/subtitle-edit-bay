# 字幕の自動・手動改行

字幕の改行は、通常は日本語の区切り、表示幅、表示時間を考慮して自動で決定します。字幕ごとの行数を選ぶ操作はありません。

## GUIでの使い方

1. 文字起こし後、`字幕を編集する` を開きます。
2. 字幕一覧の本文欄には、自動整形で決まった改行位置も表示されます。
3. 改行位置を変える場合は、本文欄で改行を削除するか、`Enter` で任意の位置へ入れ直します。
4. 動画プレビューで表示を確認し、問題なければ動画を書き出します。

入力中の本文と改行は動画プレビューへ即時反映されます。入力欄からフォーカスを外した時だけでなく、`Ctrl+S`、`ASSを更新`、`字幕を焼き付ける`、`Escape`、`メインへ戻る`、アプリ終了時にも、表示中の改行位置を手動改行として先にプロジェクトへ保存します。

## 自動改行と手動改行

- 手動改行がない本文は、自動整形で読みやすい位置へ改行します。
- 手動改行がある本文は、その位置を自動整形より優先します。
- 手動改行で区切った各行が表示幅を超える場合は、その行の中だけを追加で自動折り返しします。
- プレビューでは通常の改行、ASSでは `\N` として同じ位置を使用します。
- 手動改行をすべて削除すると、再び自動整形された改行を使用します。

## 既存プロジェクト

旧版で保存された `subtitle_line_count` の `1` / `2` は、読み込み時に `auto` へ移行します。キー自体はproject JSONの互換性を保つため残りますが、GUIから行数を選択することはありません。

## 注意点

- 自動改行のスコアリングは従来の日本語向けルールを維持します。
- 長い字幕は、文字起こし時のページ分割も併用して表示範囲へ収めます。出力プレビューが省略表示になる場合も、編集欄には省略前の全文を自動改行付きで表示します。
- 同時表示される字幕では、改行後の表示行数分を予約して重なりを防ぎます。
