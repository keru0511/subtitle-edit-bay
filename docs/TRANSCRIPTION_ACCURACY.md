# 文字起こしの誤生成と時間ずれの確認

## 繰り返しの確認候補

既存の字幕レビューを実行すると、同じ文字が5文字以上連続する字幕を `repeated_character` として確認候補に追加します。改行をまたぐ「いいい\nいい」も対象です。数字・句読点・長音符・繰り返し記号は対象外です。

これは文字列の特徴による検出であり、誤認識の断定ではありません。叫び声や笑い声など実際の発声も該当するため、字幕本文・時刻は変更せず、音声を確認して判断します。正しい発声なら既存の `false_positive` 状態を利用できます。単語の反復や音声上の無音は、このルールでは検出しません。

## 時間ずれの切り分け

再現素材が利用できる端末で、元音声、WhisperX出力JSON、編集プロジェクト、問題の時刻を比較します。

- 全体で一定のずれ：動画と録音の同期オフセットを確認します。
- 一部の字幕だけのずれ：出力JSONのセグメント・単語時刻と字幕分割後の時刻を比較します。
- 後半ほど大きくなるずれ：冒頭・中盤・末尾で同期差を比較します。現在の一律オフセットでは時間とともに変化するずれを補正できません。

設定変更による比較では、古い文字起こしキャッシュを使わず再実行してください。元音声での比較が済むまでは、誤生成の抑制効果や時間ずれの改善を確認済みとは扱いません。
