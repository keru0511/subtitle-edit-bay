# 実音声による文字起こしCI

`.github/workflows/transcription-accuracy.yml` は文字起こし関連のPRで、固定した日本語実録音をWhisperXの実モデルで認識します。通常のモックテスト、既存の電子音スモークテストとは別の検証です。

## 実行条件

Windowsのホストランナー、Python 3.10、製品のCPUロックファイル、`large-v3`、日本語、CPU int8を使用します。モデルの初回ダウンロードを含み、通常の単体テストより時間がかかります。新しいGPUランナーや認証情報は不要です。処理中に失敗した場合も成功扱いにせず、認識ログを成果物へ残します。

PRではイベントのbase SHAとマージ候補を別checkoutに読み込みます。手動実行では`compare_ref`で比較対象を指定できます。評価器と固定素材は両方の認識に同じものを使い、各checkoutの製品用コマンド生成関数と既定VAD値を読み込んで実行します。認識結果のキャッシュは使いません。WhisperX/PyTorchなどのバージョン、両checkoutのSHA、実行コマンド、音声ハッシュを記録します。

## 評価内容

- 正解文に対する文字誤り率（CER）、挿入・脱落・置換の数
- 無音・雑音区間に出た文字数
- 語時刻の欠損、不正な字幕時刻
- 正解文字列との対応から求める、既知の発話区間からの時刻逸脱
- 処理時間（モデル読み込み・初回ダウンロードを含む参考値。速度比較の合否判定には使わない）

文字の正規化は全半角・英字大小・句読点・空白だけです。繰り返しを削除してスコアを良くすることはしません。全文が空なら脱落として失敗します。正しい文でも別の発話区間へずれれば失敗します。

合否の基準は `assets/asr_benchmark/manifest.json` に固定します。文字誤り率25%を超えた場合、旧版よりCER・挿入・脱落が悪化した場合、許容0.4秒を超えて発話区間外へ出た文字、時刻欠損、不正時刻がある場合はジョブを失敗させます。同じ結果で合格しても「改善した」とは扱いません。

単語ごとの正解開始・終了時刻は用意できていません。現時点の時刻指標は録音配置区間からの逸脱であり、単語境界の誤差ではありません。実際のゲーム実況への効果も、この小さな朗読素材では証明できません。

## 成果物とローカル実行

Actionsのサマリーに比較表を出し、`transcription-accuracy-<run id>` に音声、両認識JSON、実行コマンド、ログ、JSON/Markdownレポートを14日間保存します。

同じランタイムを用意した端末では、次のように実行できます。

```sh
python scripts/benchmark_transcription.py --baseline-root ../baseline --candidate-root . --output out/asr-report
```

評価器の単体テストは通常のportable-unitグループに含めます。実認識ジョブには推論モックを使いません。
