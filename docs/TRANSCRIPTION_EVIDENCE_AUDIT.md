先行する[実認識CI 36152077399](https://github.com/keru0511/subtitle-edit-bay/actions/runs/36152077399)では、同じmainコミット・同じ音声ハッシュで生CERが6.59%、変更後が7.69%でした。最新実行では両方7.69%です。旧版の認識表記「あとから／後から」が実行間で変わったため、先行する単回比較だけで本文精度の悪化や改善を断定できません。

配布元の[Kokoro Speech Dataset](https://github.com/kaiidams/Kokoro-Speech-Dataset)はLibriVoxの朗読から音声を切り出し、本文との対応を自動で作っています。参照文は配布元のメタデータであり、この作業では実際の音を聴いて逐語的に確定していません。CIのCERはその参照文に対する値です。

## 確認できていないことと処置

- 提供された実況動画の一部はモデルへ入力し、新旧の認識出力を比較した。しかし音を聴いて逐語正解を作っておらず、「いいいいいい」のような文字列が実際の発声か、誤挿入か、脱落かを判定していない。**出力同士の差を精度改善と呼んだ説明は誤り。**
- PR #446の反復ペナルティ1.1、探索数10、15秒チャンク、VAD既定値が実況の誤挿入を減らすかは未検証。PR #446のCIは粗い時刻逸脱の改善を示すが、複数設定を同時に変えたため原因も分離できない。マージ済み設定の効果を確定したものとして扱わない。
- PR #456で追加した反復ペナルティ1.2は、正解なしの実況出力比較を根拠にしていたため、コミット `ee5e543` で取り消した。PR #456はドラフトに戻した。
- PR #456のCIは既存の朗読4件を加工して増やしたもので、実況の叫び声、笑い声、複数話者、自然なBGM・効果音、長時間の同期を代表しない。120秒は入力ファイルの長さ、約31.0秒は配置した録音クリップ長の合計であり、有声音の長さではない。
- 合否用CERは5組の表記差を統一する。生CERと元の参照文・認識文も保持し、実際の言い間違いを表記差として隠していないか確認できるようにする。ただし参照文自体の聴取確認は別途必要。
- 今後「実況で言っていない語句が減った」「単語時刻の精度が上がった」と主張するには、元音声を聴いて確認した逐語文・発話と無音の範囲・必要な単語境界を固定し、同じ区間を旧版と新版の両方で採点する必要がある。現時点のCI合格はその代わりにならない。
