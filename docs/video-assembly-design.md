# 動画連結・シーケンス結合モード (Video Join & Sequence Assembly Mode)

ゲーム実況動画や配信アーカイブの編集において、複数に分割された録画ファイル、オープニング（OP）、アイキャッチ、ゲームプレイ本編、エンディングカード（ED）を直感的に並べ、不要な前後の遊びをトリミングし、滑らかなトランジションやつなぎ目処理（音量均一化）を施して1本のシーケンスにまとめるための専用UIおよびパイプライン設計を定義する。

---

## 1. 目的とワークフロー上の位置付け

### 1.1 課題とユースケース
- **分割録画の統合**: 長時間配信やOBSによるセッション分割（パート1、パート2…）を、1本の本編タイムラインに結合したい。
- **OP/EDの定型合成**: チャンネル固定のオープニング動画やチャンネル登録促進エンディングカードを前後に差し込みたい。
- **ハイライト・チャプターの接続**: 複数の見どころクリップをあらかじめ連結した状態から本編字幕入れに入りたい。
- **音量・フォーマットの不揃い**: 各素材で音声レベルや録画フレームレートが微妙に異なる場合、つなぎ目で音量ショックや再生ズレが発生する。

### 1.2 編集モードレールとタイムラインツールバーの統合構成
本リポジトリのデスクトップUI（`MainWorkflowScreen` / `ui-redesign-mockup.html`）では、制作プロセスの責務分離とプロ仕様NLEのメンタルモデルに基づき、「結合」と「カット」を単一の**「🎬 編集モード」**に統合している。

```
[🎬 編集 (カット・移動・結合)] ──> [💬 字幕] ──> [🔊 音量]
 (本編の組み立て・カット・整音)    (テロップ入れ)   (BGM・整音)
```

タイムライン上部のツールバー（無音自動検出とズームの間）に、以下の**3連ツールスイッチ**を常設し、制作段階に応じてシームレスに切り替える：
- **`✂️ カット` (Cut)**: 無音区間自動検出、タイムライン範囲指定、非破壊カット削除
- **`✋ シーケンス移動` (Move)**: クリップやBGMを掴んで前後に並び替え、In/Out伸縮、音ズレ補正
- **`🔗 動画結合` (Join)**: 左上素材一覧（メディアビン）展開、複数動画ノードのD&D取り込み、つなぎ目トランジション設定、OP/ED自動スロット、Loudnorm音量均一化

### 1.3 シーケンス移動におけるマルチトラック音声設計
動画編集（特にゲーム実況動画）において、クリップは映像単体ではなく**「映像トラック」と「実況マイクやゲーム音声などの音声トラック」がペア**で存在し、さらに**BGMや効果音（SE）の配置**が作品のクオリティを決定づける。そのため、シーケンス移動機能は以下のオーディオ操作を包括する：

1. **映像・音声リンク移動（Linked Move, デフォルト: ON 🔗）**:
   - V1映像クリップを掴んで並び替えたりIn/Outトリムした際、A1連動音声トラックも自動で完全同期して追従移動。
2. **リンク解除と音ズレ補正（Audio Slip / J-Lカット ⛓️‍💥）**:
   - キャプチャ機器やOBS録画で発生しがちなマイク音声とゲーム映像のミリ秒単位のズレ（`±0.1s`）を直感修正。また、映像が切り替わる前に音声を先出しする「Jカット」、余韻を残す「Lカット」に対応。
3. **独立オーディオトラック（A2: BGM / 効果音 SE）の自由移動**:
   - 盛り上がるシーンやハイライトに合わせて、BGMやSEブロックをタイムライン上で左右にドラッグして鳴り始め位置を配置。

## 2. 画面レイアウトと操作仕様

本機能は、Premiere ProやDaVinci Resolveなどの本格的ノンリニア動画編集ソフト（NLE）の標準的な画面構成を採用し、直感的なドラッグ＆ドロップと直接カット操作をサポートする。

```
+----------------------------------------------------------------------------------------------------+
| ヘッダー: プロジェクト名 • モード表示 • [ 📱 ショート作成 ] • [ ⤓ 動画を書き出す ]                 |
+---+------------------------------------+-------------------------------------------+---------------+
| 🎬| 📁 素材一覧 (動画結合時のみ展開)   | 📺 モニター (プレビュー)                  | 🛠️ プロパティ |
| 編| - PCからD&D追加                    |                                           | - 連結実効総尺|
| 集| - ドラッグでシーケンスへ取り込み   |                                           | - OP/ED設定   |
|   +------------------------------------+-------------------------------------------+ - A1音声設定  |
| 💬| ツールバー:                                                                    |   (音量/ズレ) |
| 字| [無音検出] [↶][↷]  ★[ ✂️ カット | ✋ シーケンス移動 | 🔗 動画結合 ]★  [ズーム][スナップ]   | - BGM/SE設定  |
| 幕|--------------------------------------------------------------------------------+   (位置/フェード
|   | シーケンス操作バー: [ 🔗 映像・音声リンク: ON ] [ ✂️ 分割 ] [ I ] [ O ] [ +BGM ] [ +SE ]         |
```

### 2.1 左上: 素材一覧パネル（メディアビン / Asset Pool）
- **表示切り替え**: `🔗 結合` モード選択時のみプレビューの左側に展開（幅 `w-80`）。通常のカット・字幕・音量モード時は自動的に隠れ、プレビューモニターが全幅表示される。
- **PCファイルドロップゾーン**:
  - エクスプローラーやデスクトップから動画ファイルを直接ドラッグ＆ドロップして即時インポート。
  - `[+ 追加]` ボタンからファイル選択ダイアログによる追加も可能。
- **ドラッグ可能な素材カード (`draggable="true"`)**:
  - 素材名、尺（`00:15` / `12:30`）、解像度・fps（`1080p 60fps`）、スロット属性（`OP` / `本編` / `ED` / `素材`）。
  - ドラッグハンドル（`⋮⋮`）またはカード全体を掴み、下部のシーケンスバーの任意の位置へドラッグ＆ドロップして配置。
  - ホバー時に `[+ 挿入]` ボタンを表示し、ワンクリックでシーケンス末尾へ追加も可能。

### 2.2 下部: 結合シーケンスバー（Sequence Bar & In-place Trimming）
- **D&Dドロップ受け付け (Drop Target)**:
  - 素材一覧またはPCエクスプローラーからドラッグしてきた際、青い**挿入インジケーター（Vertical Drop Indicator）**がマウス位置のクリップ境界にリアルタイム表示される。
  - クリップとクリップの間、先頭、末尾など、狙った位置へダイレクトにクリップを挿入可能。
- **シーケンスバー上でのD&D並び替え (Reorder by Drag & Drop)**:
  - 配置済みクリップ自体も `draggable="true"`。
  - クリップを掴んで別の位置へドラッグ＆ドロップするだけで、直感的に再生順序を入れ替え可能。
- **その場でのIn/Outトリムカット (Direct Trimming)**:
  - 各クリップの両端に **左トリムハンドル (`◀`)** と **右トリムハンドル (`▶`)** を常設。
  - クリックまたはドラッグで開始カット（In点）と終了カット（Out点）を直接調整。
- **再生位置での分割カット (`✂️ 分割`)**:
  - シーケンスバー上部のツールバーに **`✂️ 再生位置で分割`**、`[ I ] In点`、`[ O ] Out点`、`🗑️ 削除` ボタンを完備。
  - クリップの途中で不要なシーンがある場合、再生位置で2分割して不要側を除外可能。
- **つなぎ目トランジションバッジ**:
  - 各クリップの境界に `🔀 トランジションバッジ` を配置。クリックで `クロスフェード` ⇄ `黒フェード` ⇄ `カット` を直接トグル切り替え可能。

### 2.3 右側インスペクター（シーケンス設定パネル）
- **シーケンス情報サマリー**:
  - 連結後の有効総尺（実効尺）、素材クリップ数、統一出力解像度・fps（例: `1080p 60fps`）をリアルタイム計算して表示。
- **クイックOP/EDスロット**:
  - `[🎬 オープニング]` ボタン: 先頭（Index 0）にOPクリップを自動挿入または置換。
  - `[🏁 エンディング]` ボタン: 末尾にEDクリップを自動追加または置換。
- **グローバルトランジション設定**:
  - 一括トランジションタイプ（`クロスフェード`、`黒フェード`、`カット (即時)`）とオーバーラップ時間（`0.5s` など）を指定し、全クリップ間のつなぎ目に一括適用。
- **音量自動均一化トグル (EBU R128 Loudnorm -16 LUFS)**:
  - 異なる環境やマイクで録音された素材間の音量レベル差を解消するため、`src/assemble_video.py` の `build_loudnorm_filter()` と連携するトグルスイッチを常設。
- **クリップ詳細・微調整カード**:
  - クリップ一覧、In/Out数値微調整、順序入れ替え（`▲ / ▼`）、除外。

### 2.4 アクション実行導線
1. **「本編編集へ進む (カット・字幕)」 (`commitJoinToMainEditor()`)**:
   - 連結された全クリップを統合タイムラインにマッピングし、非破壊カット・文字起こし字幕モードへシームレスに移行。
2. **「結合動画を書き出す」 (`exportJoinedVideoQuick()`)**:
   - 字幕入れを行わず、複数素材の結合と音量均一化のみを即座に行いたい場合のワンクリック書き出し。

## 3. データモデル

```typescript
// 結合モードの動画クリップ定義 (V1 映像 + A1 連動音声)
interface JoinClip {
  id: number | string;
  slot: "op" | "main" | "ed" | "clip";
  title: string;
  file: string;
  duration: number;        // 元ファイルの総尺 (秒)
  startSec: number;        // カット開始 (In点, 秒)
  endSec: number;          // カット終了 (Out点, 秒)
  resolution: string;      // "1080p 60fps"
  transition: "クロスフェード" | "黒フェード" | "カット";
  transDur: number;        // トランジション継続時間 (秒, 0.5等)
  // 連動音声 (A1) 設定
  audioLinked: boolean;    // 映像と連動移動するか (true: 同期, false: 単独スリップ)
  audioVolume: number;     // 音量 (0〜200%)
  audioOffsetSec: number;  // 音ズレ補正 (秒, ±0.1s 等)
  audioMuted: boolean;     // ミュートフラグ
}

// 独立オーディオクリップ定義 (A2 BGM / 効果音 SE)
interface JoinAudioClip {
  id: string;
  type: "bgm" | "se";
  title: string;
  file: string;
  offsetSec: number;       // タイムライン上の再生開始位置 (秒)
  duration: number;        // 音声尺 (秒)
  volume: number;          // 音量 (0〜200%)
  fadeIn: number;          // フェードイン (秒)
  fadeOut: number;         // フェードアウト (秒)
  loop: boolean;           // ループ再生
  ducking: boolean;        // トーク時の自動音量低減 (BGM用)
}

// 結合シーケンス状態
interface JoinSequenceState {
  clips: JoinClip[];
  audioClips: JoinAudioClip[];
  globalAudioLinked: boolean;
  selectedClipId: number | string | null;
  selectedAudioId: string | null;
  loudnormEnabled: boolean;
  globalTransitionType: "クロスフェード" | "黒フェード" | "カット";
  globalTransitionDur: number;
}
```

### 実効総尺の計算式
つなぎ目がクロスフェード等のオーバーラップを伴う場合、全体の再生時間は次のように算出される：

$$\text{EffectiveDuration} = \sum_{i=0}^{N-1} (endSec_i - startSec_i) - \sum_{i=0}^{N-2} \text{transDur}_i \quad (\text{if } transition_i \neq \text{"カット"})$$

## 4. バックエンド連携 (`src/assemble_video.py` & `src/multi_source_short_video.py`)

既存のPythonモジュールとの対応関係は以下の通りであり、追加のアーキテクチャ破壊なしに直接バインド可能。

| GUI操作 / 設定 | 既存バックエンドモジュール | 実装関数・定数 |
| :--- | :--- | :--- |
| **音量均一化 (Loudnorm)** | `src/assemble_video.py` | `build_loudnorm_filter(-16.0, 11.0, -1.5)` |
| **フレームレート・解像度統一** | `src/assemble_video.py` | `build_normalize_command()` (`-r 60`, `-pix_fmt yuv420p`, `48000Hz`) |
| **無劣化/高速結合マニフェスト** | `src/assemble_video.py` | `write_concat_manifest()` / `build_concat_command()` |
| **複数素材・クロスフェード** | `src/multi_source_short_video.py` | `build_concat_filter_script()` (xfade, acrossfade) |
| **OP/EDスロット処理** | `src/assemble_video.py` | `assemble_video(opening_clip, main_clip, ending_clip)` |

## 5. UIプロトタイプ（`docs/ui-redesign-mockup.html`）での確認手順

1. ブラウザで `docs/ui-redesign-mockup.html` を開く。
2. 左側のモードレールで **`🎬 編集`** を選択。
3. タイムライン上部ツールバー中央のスイッチで操作ツールを切り替える：
   - **`✂️ カット (C)`**: マルチトラック波形タイムライン、無音自動検出、ドラッグ範囲カット。
   - **`✋ シーケンス移動 (V)`**: クリップを掴んで並び替え、In/Outトリム、BGMドラッグ移動。
   - **`🔗 動画結合`**: 左上に「素材一覧」を展開、PC/一覧からのD&D取り込み、OP/ED設定。
4. **マルチトラック音声（V1 / A1 / A2）の確認**:
   - **V1 映像 ＋ A1 連動音声**: 映像クリップの下に完全同期するA1音声波形ブロックが表示されることを確認。
   - **リンク移動**: ツールバーの `[ 🔗 映像・音声リンク: ON ]` 状態で映像クリップを並び替えると、A1音声も連動して一緒に移動することを確認。
   - **リンク解除＆音ズレ補正**: `[ 🔗 映像・音声リンク: ON ]` をクリックして `⛓️‍💥 リンク解除` にすると、A1音声の `◀ 0.1s` / `0.1s ▶` ボタンで音ズレ（スリップオフセット）を個別に微調整できることを確認。
   - **A2 BGM / SEトラック**: タイムライン上のBGMや効果音ブロックを左右にドラッグして、開始位置（秒）を自由に移動できることを確認。
   - **インスペクター設定**: 右パネルでクリップのA1音量や音ズレ補正、BGMの開始タイミング、フェードイン/アウト、ダッキング設定が変更できることを確認。
5. 「本編編集へ進む」をクリックすると、結合結果を保持したままカット・字幕編集モードへ移行する。
