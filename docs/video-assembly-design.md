# 動画連結・シーケンス結合モード (Video Join & Sequence Assembly Mode)

ゲーム実況動画や配信アーカイブの編集において、複数に分割された録画ファイル、オープニング（OP）、アイキャッチ、ゲームプレイ本編、エンディングカード（ED）を直感的に並べ、不要な前後の遊びをトリミングし、滑らかなトランジションやつなぎ目処理（音量均一化）を施して1本のシーケンスにまとめるための専用UIおよびパイプライン設計を定義する。

---

## 1. 目的とワークフロー上の位置付け

### 1.1 課題とユースケース
- **分割録画の統合**: 長時間配信やOBSによるセッション分割（パート1、パート2…）を、1本の本編タイムラインに結合したい。
- **OP/EDの定型合成**: チャンネル固定のオープニング動画やチャンネル登録促進エンディングカードを前後に差し込みたい。
- **ハイライト・チャプターの接続**: 複数の見どころクリップをあらかじめ連結した状態から本編字幕入れに入りたい。
- **音量・フォーマットの不揃い**: 各素材で音声レベルや録画フレームレートが微妙に異なる場合、つなぎ目で音量ショックや再生ズレが発生する。

### 1.2 編集モードレールとタイムラインツールバーの統合構成
本リポジトリのデスクトップUI（`MainWorkflowScreen` / `ui-redesign-mockup.html`）では、制作プロセスの責務分離とプロ仕様NLEのメンタルモデルに基づき、「結合」と「カット」を単一の**「🎬 編集モード」**に統合している。

```
[🎬 編集 (カット・移動・結合)] ──> [💬 字幕] ──> [🔊 音量]
 (本編の組み立て・カット・整音)    (テロップ入れ)   (BGM・整音)
```

タイムライン上部のツールバー（無音自動検出とズームの間）に、以下の**3連ツールスイッチ**を常設し、制作段階に応じてシームレスに切り替える：
- **`✂️ カット` (Cut)**: 無音区間自動検出、タイムライン範囲指定、非破壊カット削除
- **`✋ シーケンス移動` (Move)**: クリップやBGMを掴んで前後に並び替え、In/Out伸縮、音ズレ補正
- **`🔗 動画結合` (Join)**: 左上素材一覧（メディアビン）展開、複数動画ノードのD&D取り込み、つなぎ目トランジション設定、OP/ED自動スロット、Loudnorm音量均一化

### 1.3 シーケンス移動におけるマルチトラック音声設計
動画編集（特にゲーム実況動画）において、クリップは映像単体ではなく**「映像トラック」と「実況マイクやゲーム音声などの音声トラック」がペア**で存在し、さらに**BGMや効果音（SE）の配置**が作品のクオリティを決定づける。そのため、シーケンス移動機能は以下のオーディオ操作を包括する：

1. **映像・音声リンク移動（Linked Move, デフォルト: ON 🔗）**:
   - V1映像クリップを掴んで並び替えたりIn/Outトリムした際、A1連動音声トラックも自動で完全同期して追従移動。
2. **リンク解除と音ズレ補正（Audio Slip / J-Lカット ⛓️‍💥）**:
   - キャプチャ機器やOBS録画で発生しがちなマイク音声とゲーム映像のミリ秒単位のズレ（`±0.1s`）を直感修正。また、映像が切り替わる前に音声を先出しする「Jカット」、余韻を残す「Lカット」に対応。
3. **独立オーディオトラック（A2: BGM / 効果音 SE）の自由移動**:
   - 盛り上がるシーンやハイライトに合わせて、BGMやSEブロックをタイムライン上で左右にドラッグして鳴り始め位置を配置。

### 2.1 左上: 素材一覧パネル（メディアビン / Asset Pool）
- **常設表示仕様**: 「🎬 編集モード」選択中は、どの編集ツール（`✂️ カット`、`✋ シーケンス移動`、`🔗 動画結合`）がアクティブであっても、常にプレビューモニター左側に素材一覧が常設表示される（幅 `w-80`）。ツールを切り替えても素材一覧が閉じないため、カットや移動作業中も手元で追加素材をいつでも確認・ドラッグ＆ドロップできる。「💬 字幕」または「🔊 音量」サブモードへ切り替えた時のみ自動的に折りたたまれ、作業領域が最大化される。
- **カテゴリフィルタータブ**:
  - `すべて` / `🎬 動画` / `🎵 BGM/SE` のタブボタンを完備。動画クリップだけでなく、BGM楽曲や効果音（SE）を素早く絞り込み・検索可能。
- **PCファイルドロップゾーン**:
  - エクスプローラーやデスクトップから動画・音声ファイル（mp4, mp3, wav等）を直接ドラッグ＆ドロップして即時インポート。
  - `[+ 追加]` ボタンからファイル選択ダイアログによる追加も可能。
- **ドラッグ可能な素材カード (`draggable="true"`)**:
  - 素材名、尺（`00:15` / `12:30`）、解像度・サンプリング周波数（`1080p 60fps` / `48kHz Stereo`）、スロット属性（`OP` / `本編` / `ED` / `BGM` / `SE` / `素材`）。
  - ドラッグハンドル（`⋮⋮`）またはカード全体を掴み、下部のシーケンスバーまたはオーディオトラックの任意の位置へドラッグ＆ドロップして配置。
  - ホバー時に `[+ 挿入]` ボタンを表示し、動画ならシーケンス末尾へ、音声ならBGMトラックへワンクリック追加も可能。

### 2.2 下部: 結合シーケンスバー（Sequence Bar & In-place Trimming）
- **D&Dドロップ受け付け (Drop Target)**:
  - 素材一覧またはPCエクスプローラーからドラッグしてきた際、青い**挿入インジケーター（Vertical Drop Indicator）**がマウス位置のクリップ境界にリアルタイム表示される。
  - クリップとクリップの間、先頭、末尾など、狙った位置へダイレクトにクリップを挿入可能。
- **シーケンスバー上でのD&D並び替え (Reorder by Drag & Drop)**:
  - 配置済みクリップ自体も `draggable="true"`。
  - クリップを掴んで別の位置へドラッグ＆ドロップするだけで、直感的に再生順序を入れ替え可能。
- **その場でのIn/Outトリムカット (Direct Trimming)**:
  - 各クリップの両端に **左トリムハンドル (`◀`)** と **右トリムハンドル (`▶`)** を常設。
  - クリックまたはドラッグで開始カット（In点）と終了カット（Out点）を直接調整。
- **再生位置での分割カット (`✂️ 分割`)**:
  - シーケンスバー上部のツールバーに **`✂️ 再生位置で分割`**、`[ I ] In点`、`[ O ] Out点`、`🗑️ 削除` ボタンを完備。
  - クリップの途中で不要なシーンがある場合、再生位置で2分割して不要側を除外可能。
- **つなぎ目トランジションバッジ**:
  - 各クリップの境界に `🔀 トランジションバッジ` を配置。クリックで `クロスフェード` ⇄ `黒フェード` ⇄ `カット` を直接トグル切り替え可能。

### 2.3 右側インスペクター（シーケンス設定パネル）
- **シーケンス情報サマリー**:
  - 連結後の有効総尺（実効尺）、素材クリップ数、統一出力解像度・fps（例: `1080p 60fps`）をリアルタイム計算して表示。
- **クイックOP/EDスロット**:
  - `[🎬 オープニング]` ボタン: 先頭（Index 0）にOPクリップを自動挿入または置換。
  - `[🏁 エンディング]` ボタン: 末尾にEDクリップを自動追加または置換。
- **グローバルトランジション設定**:
  - 一括トランジションタイプ（`クロスフェード`、`黒フェード`、`カット (即時)`）とオーバーラップ時間（`0.5s` など）を指定し、全クリップ間のつなぎ目に一括適用。
- **音量自動均一化トグル (EBU R128 Loudnorm -16 LUFS)**:
  - 異なる環境やマイクで録音された素材間の音量レベル差を解消するため、`src/assemble_video.py` の `build_loudnorm_filter()` と連携するトグルスイッチを常設。
- **クリップ詳細・微調整カード**:
  - クリップ一覧、In/Out数値微調整、順序入れ替え（`▲ / ▼`）、除外。

### 2.4 タイムライングリッド線・マグネティックスナップ・直接インタラクション仕様

#### 1. タイムライン・グリッド線（時間目盛り格子）
- **視覚デザイン**:
  - タイムライン背景全体（波形トラック、映像V1トラック、音声A1トラック、BGM A2トラック）に時間グリッド（1秒ごとのマイナー線、5秒ごとのメジャー線）を描画。
  - 暗色背景（`#0c111d`）に対して微小透明度の白線（マイナー: 2.5%、メジャー: 8%）を配置し、視認性を確保しつつ作業の邪魔にならない控えめなデザイン。
- **ズーム連動（動的スケーリング）**:
  - ツールバーのズームスライダー（50%〜250%）に連動し、CSS変数 `--grid-major-size` および `--grid-minor-size` をリアルタイム伸縮。
  - ズーム倍率を上げるほど細かな目盛り間隔（0.1s〜0.5s単位）で精密な位置合わせが可能。

#### 2. マグネティックスナップ（吸着システム）
- **吸着対象**:
  1. 時間グリッド（0.5秒刻み / 1.0秒刻み）
  2. 再生ヘッドの位置
  3. 各クリップの境界（開始In点 / 終了Out点）
- **視覚フィードバック（Snap Guide Line）**:
  - クリップのドラッグ移動時や両端の伸縮トリミング時、吸着対象に近づく（閾値 `~12px` 以内）と、垂直のシアン発光ライン（`#22d3ee`）が瞬時に点灯しピタッと吸着。
  - 上部に「🧲 00:05.00 (グリッド吸着)」などの吸着時間バッジをポップアップ表示。
- **スナップトグル**:
  - ツールバー右側に「🧲 スナップ吸着 (0.5s/端)」チェックボックスを常設し、自由配置と吸着整列を即時切り替え可能。

#### 3. クリップのスムース直接マウスドラッグ移動（Smooth Drag & Drop）
- ブラウザ標準HTML5 D&D（ゴースト画像）の弱点を克服し、マウスの `mousedown` / `mousemove` / `mouseup` による直接座標追従を実装。
- クリップを掴むとクリップが浮き上がり（半透明＋拡大＋シャドウ）、カーソル位置に応じて挿入インジケーター（青い縦棒）がスムーズにスライド。
- グリッド線や隣接クリップにスナップ吸着し、マウスを離した瞬間に即座に順序が入れ替わる。

#### 4. クリップ両端のIn/Out伸縮ドラッグトリミング（Edge Drag Trimming）
- クリップ左端（`◀`）および右端（`▶`）をマウスで掴んで左右にドラッグすると、クリップがビヨーンとリアルタイムに伸縮。
- ドラッグ中にカーソル頭上へフローティングツールチップ（例: `◀ In点: 00:03.5s (+1.5s) | 使用尺: 12.5s`）が追従表示され、グリッドにスナップ吸着。

#### 5. Razorスライスカット（Cキー / クリック即分割）
- ツールバーで「✂️ カット」が選択されている（または `C` キーを押した）時、クリップ上をクリックした位置の秒数でクリップが瞬時に「前編」と「後編」の2つにスパッと分割される。
- 分割時に閃光エフェクト（`.slice-flash`）が走り、直感的なカット感を体感できる。

#### 6. カット自動スキッププレビュー再生（Spaceキー）
- `Space` キーで再生した際、登録されているカット区間（`cuts`）に再生ヘッドが差し掛かると、自動でカット終了位置へ瞬間ジャンプ（スキップ）。
- 再生ヘッド横に「⚡ カット区間スキップ」バッジがポップアップ表示され、「不要部分をカットした後のつながりやテンポ感」をモック上で直接プレビュー・試聴可能。

### 2.5 アクション実行導線
1. **「本編編集へ進む (カット・字幕)」 (`commitJoinToMainEditor()`)**:
   - 連結された全クリップを統合タイムラインにマッピングし、非破壊カット・文字起こし字幕モードへシームレスに移行。
2. **「結合動画を書き出す」 (`exportJoinedVideoQuick()`)**:
   - 字幕入れを行わず、複数素材の結合と音量均一化のみを即座に行いたい場合のワンクリック書き出し。

## 3. データモデル

```typescript
// 結合モードの動画クリップ定義 (V1 映像 + A1 連動音声)
interface JoinClip {
  id: number | string;
  slot: "op" | "main" | "ed" | "clip";
  title: string;
  file: string;
  duration: number;        // 元ファイルの総尺 (秒)
  startSec: number;        // カット開始 (In点, 秒)
  endSec: number;          // カット終了 (Out点, 秒)
  resolution: string;      // "1080p 60fps"
  transition: "クロスフェード" | "黒フェード" | "カット";
  transDur: number;        // トランジション継続時間 (秒, 0.5等)
  // 連動音声 (A1) 設定
  audioLinked: boolean;    // 映像と連動移動するか (true: 同期, false: 単独スリップ)
  audioVolume: number;     // 音量 (0〜200%)
  audioOffsetSec: number;  // 音ズレ補正 (秒, ±0.1s 等)
  audioMuted: boolean;     // ミュートフラグ
}

// 独立オーディオクリップ定義 (A2 BGM / 効果音 SE)
interface JoinAudioClip {
  id: string;
  type: "bgm" | "se";
  title: string;
  file: string;
  offsetSec: number;       // タイムライン上の再生開始位置 (秒)
  duration: number;        // 音声尺 (秒)
  volume: number;          // 音量 (0〜200%)
  fadeIn: number;          // フェードイン (秒)
  fadeOut: number;         // フェードアウト (秒)
  loop: boolean;           // ループ再生
  ducking: boolean;        // トーク時の自動音量低減 (BGM用)
}

// 結合シーケンス状態
interface JoinSequenceState {
  clips: JoinClip[];
  audioClips: JoinAudioClip[];
  globalAudioLinked: boolean;
  selectedClipId: number | string | null;
  selectedAudioId: string | null;
  loudnormEnabled: boolean;
  globalTransitionType: "クロスフェード" | "黒フェード" | "カット";
  globalTransitionDur: number;
}
```

### 実効総尺の計算式
つなぎ目がクロスフェード等のオーバーラップを伴う場合、全体の再生時間は次のように算出される：

$$\text{EffectiveDuration} = \sum_{i=0}^{N-1} (endSec_i - startSec_i) - \sum_{i=0}^{N-2} \text{transDur}_i \quad (\text{if } transition_i \neq \text{"カット"})$$

## 4. 複数動画・複数音声の紐づけと文字起こしターゲット選択設計 (Multi-source Binding & Selective Transcription)

ゲーム実況動画の制作現場では、オープニング（OP）、本編録画（Part 1、Part 2…）、エンディング（ED）、アイキャッチなど**複数の動画素材**と、ゲーム内音声、実況者個別マイク（Craig botやオーディオインターフェース収録）、BGM楽曲、効果音（SE）など**複数の音声素材**が同時にプロジェクトへ取り込まれる。
このため、字幕生成パイプラインでは**「どの動画にどの音声を紐づけるか」**および**「素材一覧の中からどれを文字起こし（WhisperX）対象にするか」**をユーザーが明示的にコントロールできる設計が必須となる。

### 4.1 音声ソース紐づけ（Audio Source Binding）モデル
各動画クリップ（`JoinClip`）および動画素材（`MediaAsset`）は、以下の3種類の音声ソースから連動先を選択可能とする：

| 連動音声ソース | 説明 | 字幕生成時の扱い |
| :--- | :--- | :--- |
| **外部話者マイク (`craig_dual`)** | Discord Craig botやマルチマイク録音された個別話者FLAC/WAVファイル（例: `1-alice.flac`, `2-bob.flac`） | 話者ごとのトラックから個別文字起こしし、話者色（黄色/水色等）を割り当てて自動統合 |
| **動画内蔵音声 (`embedded`)** | MP4等の動画コンテナに含まれる音声ストリーム（ゲーム音＋ボイス混ざり等） | 動画音声から直接WAV抽出して文字起こし（必要に応じて話者分離ダイアライゼーション適用） |
| **音声なし / ミュート (`mute`)** | テロップや音声処理が不要な定型クリップ（BGM付きOP動画や無音アイキャッチ等） | 文字起こしパイプラインから完全除外（WhisperX推論コストをゼロ化） |

### 4.2 素材一覧からの文字起こし対象選択（Selective Transcription）
- **初期判定ルール（スマートデフォルト）**:
  - `main`（本編動画）および `speaker`（個別話者マイク音声）: 初期値 **文字起こし対象: ON**
  - `op`（オープニング）、`ed`（エンディング）、`bgm`（BGM）、`se`（効果音）: 初期値 **文字起こし対象: OFF**
- **素材一覧（メディアビン）でのクイックトグル**:
  - 素材カード上に常設された `[🎙️ 文字起こし対象]` バッジをクリックするだけで、対象のON/OFFをワンクリックでトグル可能。
- **素材紐づけ・文字起こしマネージャー (`modal-source-settings`)**:
  - 複数動画×音声の紐づけマトリクスを一覧表示。
  - 各動画のチェックボックス、紐づけ音声ドロップダウン、外部話者マイクの追加・カラー設定を一元管理。
  - 「選択サマリー（対象動画数・総尺・推定WhisperX処理時間）」を確認した上で、`[ 🎙️ 対象素材の文字起こしを開始 ]` を実行。
- **字幕インスペクタでのクリップ別フィルター**:
  - 字幕編集パネル上部に「すべて表示」「本編Part 1 (4字幕)」「本編Part 2 (2字幕)」のタブフィルターを常設。複数動画が繋がった長尺プロジェクトでも、クリップ単位で字幕を迷わず確認・編集可能。

## 6. UIプロトタイプ（`docs/ui-redesign-mockup.html`）での確認手順

1. ブラウザで `docs/ui-redesign-mockup.html` を開く。
2. 左側のモードレールで **`🎬 編集`** を選択。
3. **タイムライン・グリッドとマグネティックスナップの確認**:
   - タイムライン背景に1秒ごとのマイナー線、5秒ごとのメジャー線が表示されていることを確認。
   - ズームスライダーを動かすと、グリッド線の間隔が伸縮し拡大縮小することを確認。
   - クリップの移動やトリミング時、隣接境界やグリッドに近づくと青く光る「スナップガイド線」が点灯し吸着することを確認。
4. **シーケンス移動・トリム・スライスの使用感テスト**:
   - **クリップ直接ドラッグ移動 (`V`)**: クリップ本体をマウスで掴むと浮き上がり、左右に滑らかにスライド移動。ドロップ時にスナップして順序が入れ替わることを確認。
   - **In/Out伸縮トリミング (`◀ / ▶`)**: クリップ両端のハンドルをマウスでドラッグすると、クリップがビヨーンと伸縮し、頭上にタイムコードツールチップ（例: `In点: 00:02.5s (+1.0s)`）が追従することを確認。
   - **BGMドラッグ移動**: A2トラックのBGMブロックをマウスで掴んで左右にドラッグ移動し、再生位置がスムーズに変更できることを確認。
   - **Razorスライスカット (`C`)**: `C` ツール選択時にクリップ上の任意の位置をクリックすると、その位置でクリップが瞬時に2分割（閃光演出）されることを確認。
5. **カット自動スキップ再生の確認**:
   - `Space` キーで再生を開始し、再生ヘッドが赤色のカット区間に突入すると、自動でカット終了位置へジャンプ（スキップ）し、「⚡ カット区間スキップ」バッジが表示されることを確認。
6. **マルチトラック音声（V1 / A1 / A2）の確認**:
   - **V1 映像 ＋ A1 連動音声**: 映像クリップの下に完全同期するA1音声波形ブロックが表示されることを確認。
   - **リンク移動**: ツールバーの `[ 🔗 映像・音声リンク: ON ]` 状態で映像クリップを並び替えると、A1音声も連動して一緒に移動することを確認。
   - **リンク解除＆音ズレ補正**: `[ 🔗 映像・音声リンク: ON ]` をクリックして `⛓️‍💥 リンク解除` にすると、A1音声の `◀ 0.1s` / `0.1s ▶` ボタンで音ズレ（スリップオフセット）を個別に微調整できることを確認。
7. 「本編編集へ進む」をクリックすると、結合結果を保持したままカット・字幕編集モードへ移行する。
